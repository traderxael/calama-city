# Calama City

Juego 3D de mundo abierto en el centro de Calama, Chile. Conducción libre tipo GTA (sandbox).

Motor: **Unity 6000.6.5f1** + URP

## Cómo abrir

1. Unity Hub → Add project → esta carpeta, con Unity **6000.6.5f1**.
2. Abrir `Assets/Scenes/MainMenu.unity` y darle Play.

## Controles

| Acción | Tecla |
|--------|-------|
| Mover personaje | `WASD` |
| Correr | `Shift` + `WASD` |
| Saltar | `ESPACIO` |
| Entrar/salir del coche | `E` |
| Conducir | `W` / `S` / `A` / `D` |
| Pausa | `ESC` |
